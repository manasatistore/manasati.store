# متجر منصتي (Manasati Store) - متجر الاشتراكات الرقمية المتكامل

متجر إلكتروني متكامل وفاخر لبيع كافة أنواع الاشتراكات الرقمية (نتفليكس، شاهد VIP، يوتيوب بريميوم، أدوات الذكاء الاصطناعي، الألعاب والرياضة) بتصميم عربي ناطق بالكامل ودعم RTL، وتأثيرات بصرية فاخرة (Neon & Glassmorphism).

---

## 🌟 مميزات المشروع

### 1. واجهة العميل (Customer Front Store):
- **الهوية البصرية**: ألوان داكنة فاخرة، وتأثيرات زجاجية وإضاءات بنفسجية ونيلية نيون.
- **تصفح وتصفية الاشتراكات**:
  - تصفية فورية بحسب التصنيف (ترفيه وسينما، ذكاء اصطناعي وتصميم، ألعاب وااشتراكات، رياضة، موسيقى).
  - بحث سريع فوري في أسماء وتفاصيل الخدمة.
  - ترتيب المنتجات حسب الأكثر مبيعاً، الأسعار، أو التاريخ.
- **بطاقات الاشتراكات**: عروض للخدمات، وسوم مميزة (الأكثر مبيعاً، خصم 40%، تفعيل رسمي)، تفاصيل الضمان، وسعر التخفيض.
- **سلة تسوق تفاعلية Drawer**: إضافة/تعديل/حذف الكميات وحساب الإجمالي الفوري.
- **إتمام الطلب التفاعلي**: نماذج إدخال البيانات، اختيار طريقة الدفع (مدى، Apple Pay، STC Pay)، وإنشاء كود تفعيل ومتابعة فورية عبر الواتساب.
- **قسم الآراء والتقييمات وثقة العملاء**.

### 2. لوحة الإدارة (Admin Dashboard):
- **التبديل بين الوضعين**: زر تبديل علوي يتيح الانتقال الفوري بين واجهة الزبون ولوحة التحكم.
- **إحصائيات حية**: إجمالي عدد الخدمات، إجمالي الطلبات، المبيعات التقديرية، وحالة التفعيل.
- **نظام كامل لـ CRUD الخدمات**:
  - **عرض جميع الخدمات**: جدول بيانات منظم مع الصور والتصنيفات والأسعار.
  - **إضافة خدمة جديد (Create)**: نافذة تتيح إدخال الاسم، التصنيف، السعر، مدة الاشتراك، الوسم، رابط الصورة، والوصف.
  - **تعديل خدمة (Update)**: تعديل أي خدمة حالية وتحديثها مباشرة.
  - **حذف خدمة (Delete)**: حذف الخدمة مع تأكيد الأمن.
- **سجل الطلبات الأخير**: جدول يوثق الطلبات المستلمة وأسماء العملاء وأرقام هواتفهم.
- **تخزين دائم (LocalStorage)**: حفظ كافة التغييرات على الخدمات والطلبات والسلة تلقائياً في المتصفح.

## 📂 هيكل الملفات

```
manasati-store/
├── index.html        # الصفحة الرئيسية والواجهات واللوحات وقوائم الحوار
├── styles.css        # نظام التصميم البصري والألوان والتنسيقات المتجاوبة
├── app.js            # برمجة التفاعل والتصفية والسلة ولوحة الإدارة CRUD والتخزين
└── README.md         # التوثيق والشرح
```

## 🚀 طريقة التشغيل

1. يمكنك فتح الملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Safari, Firefox).
2. أو تشغيل سيرفر محلي (مثل `Live Server` أو `python -m http.server 8000`).
